# 自适应语音随访验收

随访保留呼吸、肿胀、体重和用药的核心清单。AI 模式下，模型结合病历、已记录的事实与最近 12 轮有效对话，在单次请求中提取逐字证据、生成口语回复并选择追问、继续交流或提议收尾。更正过的旧回答不进入后续有效对话上下文，多轮补充按证据保留在摘要中。

采集完成、达到一定轮数、静音或模型提议收尾均不提交随访。收尾提议明确邀请继续提问，患者仍可继续交流。明确的无补充或结束表达才触发提交，也可以手动挂断；结束这一轮的新信息先保存，自动提交不冒充患者核对过摘要。症状否定、否定结束意图及转述他人的结束语不会作为明确结束。含糊表达保留继续交流的机会。

录音在开口前保持等待，只缓存 300 毫秒前导声音。开口后约 2.5 秒安静才发送，中途继续说话会重置安静等待；仍有手动发送一句的按钮。单句上限从首次开口起累计 24 秒，包含停顿。分句不等于结束通话。

自动测试覆盖动态追问、模型请求上下文、超过十轮、收尾后继续提问、明确结束前的新事实、症状否定、否定和转述结束意图、危险生成内容回退、紧急状态在更正后保留、模型暂不可用、录音重试幂等、暂停与最后一句提交竞态，以及有界静音缓存和断续说话。紧急描述提示主动求助并停止常规提问，但患者仍可以补充或主动结束。

独立浏览器验收运行真实 Web Audio、AudioWorklet、WAV 上传与服务器音频播放路径，使用合成麦克风和固定 ASR/模型边界。已验证“提议收尾—继续提问—明确无补充后自动提交”三轮流程、最后播报后释放麦克风、医生与患者共享小结、任务完成和 390 像素页面。另以纯合成病历进行了六轮真实模型请求验证；未在生产患者记录中创建测试通话。

构建、类型检查和 Python 语音回归单独验证。合成浏览器及模型测试不能代表真人手机上的识别准确率、口音适应程度或端到端时延，需在目标手机和网络下继续体验。当前结束意图使用保守的常见表达识别；未能明确理解时可继续说明，或使用手动挂断。
