# 心衰随访采集协议草案

版本 `heart-failure-draft-v1`。本协议仍需合作医生专业审核，软件测试不代表临床验证。production 默认禁止启动未经审核的模板；医生可以在服务状态页查看当前问题并记录真实审核情况。

| 信息 | 起始问题 |
|---|---|
| 呼吸与活动 | 最近活动或休息时，呼吸感觉怎么样？ |
| 下肢肿胀 | 最近脚踝或小腿有没有肿，和之前比有什么变化？ |
| 近期体重 | 最近量过体重吗？大约是多少，是什么时候量的？ |
| 按医嘱用药情况 | 最近能按原来的医嘱用药吗，有没有遇到困难？ |
| 其他情况 | 还有什么身体情况或问题想让医生了解吗？ |

只保存患者原话能够支持的事实。不确定、没测量、拒绝回答和未采集分别保留，不能变成“正常”。不输出诊断、处方、剂量调整或临床风险评分。

按有限轮次补全采集；信息足够或最多十次回答后进入确认。拒绝继续时结束常规采集。患者更正会保留原文并更新摘要，被更正的旧证据不再作为当前事实。缺失项目仍允许请求医生协助核对，但标为未完整确认。

针对部分预设的严重不适表达（如正在喘得说不出完整句子、突然意识不清），停止常规问答并提示主动急救或就医。该检测不是完备急救识别器；不能承诺识别所有危险，也不能声称医生已经收到消息。未知或云服务失败转为人工协助，保留已保存回答。

上线前由医生确认问题措辞、适用人群、结束条件、求助提示及责任边界；如需增加临床阈值和建议，须单独设计、审核并验证，不能直接由模型自由生成。
